## 3. 產品概述

數位回聲（Digital Echo）是 水月道場 / Wonderland Center規劃中的受控數位仿生專案：以經合法授權的著作、演講、訪談等語料為基礎，重現已故先驅或思念親人的說話方式、聲音與思維框架，提供即時語音或影像互動。它不是讓 AI 自由扮演某人的聊天機器人，而是有邊界、可審計的「數位思想容器」：每一段輸出都標示「AI 仿生重現，非真人即時發言」，遇到當事人生前未曾表態的議題，系統只能以其思想框架提出標記為假設的推演，而不能代替本人表態。

資料來源採白名單：未經著作權人、出版機構或法定遺產繼承人書面授權的私密通訊不得匯入。授權合約審核、家屬同意書、敏感立場審查、聲紋所有權、心理衝擊評估與爭議言論即時熔斷（Kill-Switch），都由真人負責。重現形象僅為「回聲」，不代表該人物在法律、政治或商業上的實質代理人。

## 6. 差異化定位

**同法人（Wonderland Center）相鄰產品**

- **vs. 選擇預演（ChoiceRehearsal）**：選擇預演為安寧緩和醫療意願的教育與決策輔助，使用當事人自己的肖像生成模擬影片；數位回聲重現**已故者**的聲音與思想。兩者都涉及生死議題與 AI 生成人像，但對象、目的與法律框架不同。
- **vs. 雲遊伴行（WanderCompanion）**：雲遊伴行陪伴在世長者虛擬旅遊；數位回聲不提供旅遊或照護陪伴。

**跨法人**

- **vs. 斜槓一二三／斜槓104（AEGIS）**：**絕不可混為同一類產品。** 斜槓平台是在世專家或企業主動授權「專業能力」的商業交易，買方購買提問權利；數位回聲是已故人物的受控紀念與思想重現，授權來自繼承人與著作權人，輸出強制標示為 AI 重現、不代表本人。
- **vs. AllView 產品**：無功能重疊。

**相對於一般「AI 復活／虛擬人」服務**：差異在強制透明水印、拒絕代替本人表態、私密通訊白名單、家屬同意與 Kill-Switch 由真人執行，並把這些規則寫成合併前的阻斷條件。

| 對話主持與問答 | 多輪引導、自動追問、公開知識比對 | 爭議言論即時熔斷（Kill-Switch）、事後覆盤 |

## 技術架構

    使用者音訊（WebRTC）
      → 1. 對話閘道與 ASR（Whisper-Streaming）
      → 2. 仿生認知核心：邊界審查器 / Hybrid RAG（Milvus/Qdrant + 公開檢索）/ LLM 思維框架
      → 3. 感官渲染：串流 TTS / LiveAvatar Talking Head / Wav2Lip 唇形對齊
      → 視訊輸出：公開講座直播 / 機構活動 / 專屬互動終端
